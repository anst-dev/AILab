Agent điều phối

Nhắn yêu cầu bằng lời thường: dự án nào, mục tiêu gì, dùng CLI nào, bao nhiêu agent. Agent điều phối tự kiểm tra thư mục, chọn cách đánh giá, khởi động / dừng / merge phiên và báo lại khi phiên kết thúc.

Phiên cải tiến mới

N agent làm việc song song, mỗi agent trong một git worktree riêng. Mỗi lượt agent bị kill khi hết thời gian; kết quả đạt mới được merge vào nhánh trung tâm, các agent luôn bắt đầu lại từ bản tốt nhất.
